📖 Step-by-Step Guide: Importing Vouchers into Tally Prime / ERP 9

  1. Configure Ledger Names: Verify that the ledger names above exactly match your company's Chart of Accounts in Tally.
  2. Export XML: Select your desired date range and click Export Tally XML. Save the downloaded .xml file.
  3. Open Tally: Open Tally Prime, press Alt + O (Import) > select Vouchers.
  4. Select File: In the file path prompt, select the exported XML file and press Enter. Tally will import the vouchers automatically.
  5. Review Log: In case of any missing party ledgers, check Tally.imp log file in the Tally installation directory.
